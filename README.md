# Alberto Trujillo Mingorance

**Systems Administrator & SecOps Engineer** | [alberto.trujillomingorance.com](https://alberto.trujillomingorance.com)

Minimalist, ultra-secure personal portfolio and interactive terminal. Built with a Zero-Trust approach.

### 🛡️ Architecture & OpSec
- **Strict CSP:** Zero-trust external connections.
- **Anti-Scraping:** Obfuscated contact vectors and Base64 chunked CV distribution behind a technical clearance challenge.
- **Hardened Build:** Vite + Terser minification. Zero source-maps.
- **Edge Native:** Statically injected DOM deployed on Cloudflare Pages.

### 💻 Stack
Vanilla JS, HTML/CSS, Tailwind CSS, Cloudflare Pages.
